## Overview

Proof-of-concept Python scripts developed for baseline port scanning, service fingerprinting, and targeted vulnerability detection in an isolated lab environment.



## Repository Structure

- `scripts/` -Two directories, Used and Unused. Both contain python source code files (`scanner.py`, 			     `fingerprinter.py`, `ultimate\_scanner.py`).NB:Use files in 'Unused' directory 

- `docs/` - Final assessment report (PDF)

- `evidence/` - Execution screenshots

- `configs/` - VM network settings



## How to Run

Open cmd and type any of these commands

python scripts/scanner.py

python scripts/fingerprinter.py

python scripts/ultimate\_scanner.py
